# Azure Web PubSub (microsoft-azure-web-pubsub)
Azure Web PubSub REST API provides management of real-time publish-subscribe messaging using WebSocket connections. It supports sending messages to connections, groups, and users, managing client permissions, and configuring event handlers for serverless real-time applications.
